🦷Bolasco-Servanez Dental Clinic Management System

This Dental Clinic Management System is a web-based platform designed to manage patient records, appointment scheduling, dental history, and clinic operations with ease and efficiency.

*Features

- Patient Management (Add, Update, Delete patient profiles)
- Appointment Scheduling
- Dental Records Tracking
- User Authentication and Role-Based Access
- Dashboard with analytics


*Used

- Frontend: HTML, CSS, JavaScript 
- Backend: PHP
- Database: MySQL
